# Tasfiq’s Portfolio Website

This is my personal portfolio site, designed to showcase my work in creative coding, game design, UI/UX, and technical artistry. The site emphasizes responsive layouts, accessibility, and device-adaptive design so it looks great on both desktop and mobile.

## Highlights
- Responsive design with touch-friendly controls  
- Creative styling using glassmorphism, gradient borders, and interactive elements  
- Project galleries to display my work visually  
- Optimized performance with lightweight assets and adaptive layouts  

## Purpose
This portfolio is both a showcase of my projects and a playground for experimenting with design techniques, accessibility, and creative web styling. It reflects my identity as an artist, game developer, and designer.
